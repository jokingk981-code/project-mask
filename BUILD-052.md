# Build 052 — Urban Materiality

Adds real 3D geometry to the playable city:
- Irregular foundation courses across all generated townhouse parcels
- Selective cast-iron downpipes, drains and projecting cornices
- Five overhead wire-and-cloth runs between crowded market streets
- Four batched InstancedMesh calls for masonry/drainage infrastructure
- Existing Hall of Masks, markets, roads, masked NPC figures, masks, cinematic graphics controls preserved

Limits: no claim of photorealism, browser runtime validation or measured Chromebook FPS. Static hanging cloth; no cloth physics. No new real-time lights.
