# Project MASK Build 048 — Cinematic Architecture

Focus: actual in-game facade depth, not a generated image.

- Shared PBR materials for shadowed recessed doors, window glazing, weathered plinths and rusted metal.
- Procedural storefront arcade, projecting awnings and layered architectural details.
- Selected houses gain upper-story bay windows with projecting roof caps.
- Irregular plaster skins and damp stone ledges create facade depth.
- Reuse geometry for repetitive windows and frames.
- Preserve existing Hall of Masks, town, population, masks, movement, and settings.
- Fix stale title screen BUILD 038 label to BUILD 048.

Scope and limits:
- Facade detailing applied to roughly half the buildings to balance draw calls.
- The game remains stylized procedural Three.js, not photorealistic scanned assets.
- No claims of verified frame rate, navigation, or browser runtime.
